# Titanic Survival Prediction 🚢

A Machine Learning web application built using Logistic Regression and Streamlit that predicts whether you  would survive the Titanic disaster as a passenger based on passenger details such as class, gender, age, fare, and family members aboard.

---

# 🌐 Live Demo

https://titanic-survival-prediction-d5k3ucexs7kmz8oycglbrw.streamlit.app/

---

# ✨ Features

- Interactive Streamlit Web App
- Predicts Titanic passenger survival
- Shows survival probability percentage
- Dynamic fare selection based on passenger class
- User-friendly interface
- Success and failure animations
- Real-time prediction system

# 📊 Input Features

The model uses the following features:

- Passenger Class (`Pclass`)
- Gender (`Sex`)
- Age
- Number of Siblings/Spouse (`SibSp`)
- Fare
